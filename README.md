# Web Detailed Examination

URLを入力するだけでWebサイトを詳しく調査し、AIが日本語の診断レポートにまとめる静的Webアプリです。

## 主な機能

- URLから公開Webページを取得して解析
- HTML構造、見出し、リンク、画像、フォーム、スクリプト等の調査
- SEO、UI/UX、アクセシビリティ、レスポンシブ、パフォーマンス、基本的な安全性の診断
- ローカル検出 + AIによる総合分析
- 0〜100のカテゴリ別スコアと総合スコア
- 重大 / 注意 / 提案に分けた改善提案
- 技術詳細の確認
- 診断履歴をブラウザに保存
- OpenRouter APIキーを設定画面から登録
- APIキーはLocalStorageに保存可能
- ダークモード
- モバイル / タブレット / PCに対応したレスポンシブUI
- PWA用manifest / Service Workerを同梱

## 使い方

1. GitHub Pagesなどで公開します。
2. 「設定」からOpenRouter APIキーを入力します。
3. AIモデルは「無料モデルを自動選択（推奨）」のままでも利用できます。無料モデルの提供状況はOpenRouter側に依存します。
4. 「検査」に戻り、調べたいURLを入力します。
5. 「調べる」を押すと取得・構造解析・ローカル診断・AI診断を順に実行します。

## 重要な技術上の注意

このプロジェクトはブラウザだけで動く静的アプリです。任意サイトのHTMLをブラウザから直接取得するとCORS制限を受けるため、ページ取得には公開のJina AI Readerエンドポイントを利用しています。対象サイトのrobots.txt、利用規約、公開範囲を尊重してください。

AI通信はOpenRouter APIへブラウザから直接送信します。APIキーをGitリポジトリへ絶対にコミットしないでください。LocalStorageは暗号化された秘密保管庫ではないため、共有端末ではキーを保存しないことを推奨します。

また、本アプリの「安全性」診断は基本的な設定や公開情報の確認を目的としたものであり、脆弱性診断・侵入テスト・セキュリティ監査を保証するものではありません。
